# LLD Learning Repository

This repository contains my journey of learning **Low-Level Design (LLD)** through hands-on practice. It includes different design problems such as **Parking Lot, Library Management, Ride Sharing, ATM, Vending Machine, and more**. The implementations are intentionally started as **simple, messy, and naive designs** rather than trying to create a perfect solution from the beginning. The goal is to first understand the problem, identify entities, responsibilities, and flows, write a working solution, and then gradually improve the design using **OOP principles, SOLID principles, design patterns, and better abstractions**. This repo is primarily a learning space to improve my **object-oriented thinking, design intuition, coding skills, and interview problem-solving approach**.
